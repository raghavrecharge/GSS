# Delivery checklist

## Discovery
- [ ] Scope and authorization documented
- [ ] Page and route inventory complete for agreed scope
- [ ] Critical user flows mapped
- [ ] Evidence ledger includes viewport and state
- [ ] Unknowns and assumptions separated from observations

## Design
- [ ] Tokens documented
- [ ] Component variants inventoried
- [ ] Responsive states documented
- [ ] Keyboard/focus states considered
- [ ] Original/licensed assets used

## Architecture
- [ ] API contract documented
- [ ] Data entities and relationships documented
- [ ] Authorization model documented
- [ ] Validation and error contracts documented
- [ ] Secrets and sensitive data excluded

## Build
- [ ] No dead or fake controls
- [ ] Loading, empty, error, success states implemented
- [ ] Responsive layout implemented
- [ ] Backend validation and authorization implemented
- [ ] Synthetic fixtures and `.env.example` supplied
- [ ] Database migrations and seed strategy documented

## Verification
- [ ] Lint and type checks run
- [ ] Unit and integration tests run
- [ ] Critical browser journeys run
- [ ] Visual comparison performed at matching viewports
- [ ] Accessibility basics checked
- [ ] Known limitations documented
